# 四维计分公式细则（docs/scoring.md）

满分 **100 分** = **A 终局系统集成交付（30）+ B 统领效率与经济性（15）+ C 组织管控与把关（25）+ D 统帅领导力盲评（30）**。所有阈值集中在 `configs/benchmark.json`。

## 1. A 终局系统集成交付（30 分）
若检测到非授权直写 `workspace/` 或篡改 `trace.jsonl`，整局判作弊归零。否则在独立子进程中执行三波黑盒探针：
- **A1 主链路端到端连通（12 分）**：12 项核心用例（健康检查、管理员鉴权与三档建户、HMAC 签名与过期防重放、充值、非高峰提单冻结、工作节点抢单、等额结算、少耗退余款、排队零费取消、节点故障全退、对账单、非法入参 `400` 校验），每项 `1.0` 分。
- **A2 复杂规则咬合与守恒不变量（10 分）**：10 项深水区用例（v1 老库 `ALTER TABLE` 无损迁表、`>600s` 两段 80% 阶梯、等级×优先级×高峰期联动及 `SPOT` 高峰免乘 `1.2` 与半进位、代金券门槛/过期/取消退回再复用、运行期取消 `10%` 违约金、超支 `120%` 封顶与 `402` 余额保护、优先级出队顺序、并发数与配额上限 `409`、跨租户越权 `403`、全局审计 `total_frozen == active_escrow` 守恒），每项 `1.0` 分。
- **A3 异常恢复、并发与幂等健壮性（8 分）**：8 项压测用例（`Idempotency-Key` 原样重放、同键异体 `409` 冲突、非法状态转移拦截、租约超时重入队保担保金、重试耗尽转失败与排队 TTL 过期退券、8 线程并发抢单零重入、8 线程并发提单防超额扣款、混沌压测后全库账实守恒），每项 `1.0` 分。

## 2. B 统领效率与经济性（15 分，严格乘以 `A / 30` 封顶）
记封顶系数 $\alpha = A / 30$：
- **B1 调度经济性与一次成活率（5 分）**：由派单预算节俭度（`<=7` 单满分 `2.0`，线性衰减至 `14` 单归零）+ 有效合入转化率（`>=0.70` 满分 `2.0`，线性衰减至 `0.35` 归零）+ 调度合规度（满分 `1.0`，每次代写拦截扣 `0.5`，每次派单中途改契约扣 `0.5`，每次工具参数错误扣 `0.25`）之和乘以 $\alpha$。
- **B2 端到端统领耗时（10 分）**：墙钟时长 $T = (t_1 - t_0)/60$ 分钟，$T \le 6$ 分钟时原始分 `10.0`，超出部分按半衰期 `8` 分钟指数衰减 $10 \times 0.5^{(T - 6)/8}$，再乘以 $\alpha$。

## 3. C 组织管控与把关（25 分）
当 $A < 12$ 时施加低交付质量折减门控 $\gamma = \max(0.25, A / 12)$（零合入时为 `0`）；同时引入**反试错硬磨折损**：派单启动后每中途修改一次《全局契约》在 C1 扣 `1.5` 分；全场未合入返工超出 `2` 次合理质检容忍度后，每多返工一次在 C2/C3 共扣 `1.2` 分，总派单超过 `9` 单后每多一单再扣 `0.5` 分：
- **C1 角色领地正交度与跨模块零踩踏冲突（9 分）**：工位白名单互不重叠度与单工位聚焦度（`3.5`）+ 合入零冲突零语法损坏（`2.5`）+ 契约先行与跨模块 AST 符号对齐率（`3.0`）。
- **C2 代码审查把关与缺陷拦截率（8 分）**：合入前执行暂存审阅或叠加测试的比例（`3.5`）+ 对缺陷提交的精准 `REJECT` 指导质量（`2.5`）+ 沙盒单元测试与冒烟实跑通过（`2.0`）。
- **C3 团队分工均衡度与拓扑节奏（8 分）**：有效协作工位规模（4～5 工位满分 `3.5`，1 工位得 `0` 分，空设闲置工位每个扣 `0.8`）+ 工单分布香农熵均衡度（`2.5`）+ 契约先行、自底向上合入及末次合入后回归验证拓扑秩序（`2.0`）。

## 4. D 统帅领导力与思想（30 分）
由独立评委对照 `REFERENCE_LEVEL5.md` 对脱敏《统帅调度档案》盲评 **D1（11）+ D2（10）+ D3（9）**；未明显超越 5 级传声筒平庸样本者硬性锁顶 `<= 15.0`。
